# Модель v3

## Воздух

Ориентированные рёбра берутся из `app/data/gucheng-network.csv`. Независимые расходы x=Qe6, y=Qe5, z=Qe4. Тогда e1=e2=x+y; e3=e4=z; e7=e9=y+z; e8=x. y может быть отрицательным. Внутренние балансы соблюдаются конструкцией. Закон ветви: p_from − p_to + Hfan = R Q |Q|. При закрытии e5 условие y=0 заменяет её энергетическое уравнение; закрытая связь держит перепад давления.

H_A=3255,2 n² + 10,727 nQ − 0,044 Q²; H_B=3372,4 n² + 9,703 nQ − 0,033 Q². Коэффициенты n=1 из статьи; масштабирование скоростью — закон подобия, модельное допущение. Мощность оценена при синтетическом КПД 0,72.

Ньютон с поиском шага, до 80 итераций. Проверяются положительные внешние притоки/вытяжки, положительный напор, энергетическая невязка ≤1e−5 Па и баланс ≤1e−8 м³/с. Остановка вентилятора, обратный внешний приток и другие топологии не поддержаны. API не выдаёт успешный снимок при ошибке расчёта.

## Разбавленный метан

Для каждого внутреннего узла V dc/dt = Σ Qin cin + G − Qout c. c — объёмная доля. Направление входов определяется знаком расхода, наружный приток чистый. Одновременное явное обновление консервативно по массе; подшаг ≤5 с и ≤0,2 V/Qout. Диапазон применимости c≤5%; превышение — ошибка. Добавочный объём газа и изменение плотности не входят в воздушный расчёт. Это модель разбавленной примеси и идеального смешения, не CFD.

Объём узла = половина суммы L·A всех прилегающих ветвей. Это прозрачное укрупнение геометрии; эффективные объёмы и газовые источники не калиброваны. Контроль массы суммирует хранение, ввод источниками и вынос через внешние границы.

## Наблюдатель

Конечный набор траекторий: множители сопротивления e6 и общего газовыделения ∈ {0,5;1;2;4}. Начальная сетка — 16 стационарных режимов. Отбор по свежим измерениям и допускам сохраняется при последующем отказе канала. Обычный отказ не стирает историю. На объявленном событии неизвестного изменения параметров сохранённые концентрации перекрещиваются с новой сеткой; амплитуда скрытого изменения наблюдателю не передаётся. При этом сохраняется максимум 16 различных прошлых состояний, то есть до 256 траекторий; это дополнительное приближение без гарантии полноты.

Известные команды: скорости вентиляторов, закрытие e5, установленное сопротивление e5. Скрыты истинные сопротивление e6, газ и концентрации. Наблюдатель не имеет ссылки на эталон. Задержанные и зависшие показания показываются с возрастом, но не участвуют в текущем отборе. Пустой отбор = конфликт; прогноз и рекомендации отключаются, оболочка всех оставшихся траекторий помечена конфликтной.

Гипотезы не являются вероятностями или строгими интервалами. Необъявленный дрейф параметров, несовпадение реальности с сеткой и моделью смешения могут дать ложную точность, включая необнаруженный выход эталона.

## Решение

W(H) = сумма ширин будущего CH₄ в V5,V6,V7,V9. Для каждого отсутствующего канала модель прогнозирует показания к моменту ремонта и концентрации к H. Совместимые исходы группируются с удвоенным допуском (ошибка результата и кандидата); равные веса — соглашение опыта, не вероятностная оценка. Рейтинг = ожидаемое уменьшение W / стоимость. Фактическое восстановление запланировано в модельном времени, шаг делится на момент ремонта. Для сравнения ожидаемого и фактического эффекта сохраняется один абсолютный целевой момент. Изменение других команд/показаний также может влиять на фактический результат.
