# Реестр параметров

Все значения ниже являются синтетическими демонстрационными допущениями команды. Они не извлечены из опубликованной шахтной сети, паспорта вентилятора или промышленных измерений. Литература в SOURCES.md обосновывает тему, но не происхождение этих чисел.

| Параметр | Значение | Единица | Обоснование и ограничение |
|---|---|---|---|
| Общее сопротивление притока/возврата | 0,035 | Па·с²/м⁶ | Демонстрационная последовательная ветвь |
| Сопротивление A / B / обхода | 0,10 / 0,14 / 0,8 | Па·с²/м⁶ | Неодинаковые потоки в параллельных ветвях |
| Характеристика вентилятора | H0·n²−0,025Q² | Па | Синтетическая кривая; H0 вычислен для сохранения 600 Па в базовой рабочей точке |
| КПД | 0,72 | доля | Постоянен во всех режимах |
| Объём A / B | 1800 / 2400 | м³ | Идеально перемешанные объёмы |
| Источник CH₄ A / B | 0,35 / 0,22 | м³/с | Чистый метан; приток без метана |
| Скорость вентилятора n | 0,2–1,2 | доля номинала | Предел ползунка стенда |
| Проводимость обхода | 0,25–3 | множитель | R обхода = 0,8 / множитель |
| Допуск QA / QB | ±1,5 | м³/с | Граница ошибки свежего измерения в наблюдателе |
| Допуск QT | ±2 | м³/с | То же |
| Допуск CA / CB | ±0,12 | процентного пункта | То же |
| Стоимость QA/QB; CA/CB; QT | 2; 3; 1 | условная | Не деньги и не длительность ремонта |
| Экспериментальный порог | 1 | % об. CH₄ | Не норматив |
| Множители R_A/R_B в наблюдателе | [0,65; 2,5] | безразмерные | Непрерывный ограниченный диапазон |
| Множители G_A/G_B в наблюдателе | [0,5; 2] | безразмерные | Непрерывный ограниченный диапазон |

Начальные концентрации — равновесие базового участка. Воздух рассчитывается аналитически из Δp=RQ|Q| и балансов узлов. Метан обновляется точным решением баланса при постоянных входах за шаг.

Для перехода к реальному объекту необходимы опубликованная топология, размеры выработок, измеренные расходы и давления, характеристика вентилятора, источники CH₄ и погрешности приборов с правом использования. Простое переименование участка в название реальной шахты не создаёт калибровки.

## Опубликованный аналог

Отдельный расчёт `python -m app.reference` использует девять эквивалентных ветвей Gucheng из [Jia et al. (2025)](https://doi.org/10.1371/journal.pone.0320326), таблицу 4 и кривые раздела 4.1. Данные и атрибуция: `app/data/gucheng-network.csv`, `docs/reference/ATTRIBUTION.md`. Результат: `docs/reference-check.json`. Приняты равные внешние приведённые давления и нулевая дополнительная естественная тяга. Это условное воспроизведение опубликованного стационарного режима. Метан, объёмы смешения и ошибки датчиков из этого источника не получены.

Настраиваемые ошибки: шум 0–20 в единицах канала, задержка 0–120 с, зависание. Большие ошибки намеренно допускаются для стресс-опытов; покрытие требует ошибки в пределах допуска. Стоимость 0,1–100 усл. ед., целевая W 0,05–20 п.п. Пределы скрытых R/G для стрессов шире границ наблюдателя. Сетка 256 гипотез — только номинальная диагностика.
