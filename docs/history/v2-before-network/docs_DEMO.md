# Демонстрация пяти улучшений

1. Запустить `python -m app.server`, открыть http://127.0.0.1:8765 . Новый опыт с seed 20261025 начинает с исправных каналов. W и цель находятся сверху; порог не промышленный.
2. Зафиксировать контрольную точку, отключить измерения A. Сразу прежняя информация сохраняется; после продвижения времени диапазон растёт. Сравнить изменение физики и W.
3. Поставить паузу. Изменить стоимость доступных к восстановлению каналов; увидеть объяснение ожидаемого и диапазона выигрыша. Восстановить CA: сравнить модельный прогноз и фактический W до/после.
4. Через настройку канала добавить задержку/зависание: старое показание видно, его возраст растёт, в перечень используемых оно не входит. Сценарий смещения показывает конфликт; ремонт или явный перезапуск наблюдателя снимает его через переинициализацию, которая не выдаётся за информационный выигрыш.
5. Открыть опубликованную сеть Gucheng и сравнение стратегий. Обсудить совпадение рейтинга с простым правилом и границы покрытия.
6. Сохранить JSON, сбросить опыт и выбрать «Воспроизвести JSON». Восстанавливаются seed, команды, шаги, ошибки, стоимости и контрольная точка; сравнить время, W и статусы. Импорт локальный, без исполнения кода. Версия модели должна совпадать; максимум 4000 записей и 100000 модельных секунд.

`docs/examples/restoration.json` — готовый воспроизводимый опыт. Отдельные проверки: `python -m app.reference`, `python -m app.evaluation`. Кнопка показа эталона служит аудиту симуляции; наблюдатель его не использует.
