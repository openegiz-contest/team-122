# Модель и границы применимости

Двухзонный участок синтетический. Опубликованная сеть Gucheng рассчитывается отдельно и не превращает метановый стенд в модель этой шахты.

## Воздух и метан

Общие приток и возврат имеют суммарное R=0,035 Па·с²/м⁶. Параллельные A/B/обход: 0,10/0,14/0,8. Для этой топологии R_eq=(Σ1/√R_i)⁻². Вентилятор H=H0 n²−k Q_total², k=0,025; H0 выбран для базовой рабочей точки 600 Па. Поэтому Q_total=√(H0 n²/(R_common+R_eq+k)). Мощность HQ/0,72. Это синтетическая характеристика, без реверса, инерции и неустойчивости.

Для A/B: V dc/dt=G(1−c)−Qc, c — объёмная доля. V=1800/2400 м³, G=0,35/0,22 м³/с. Точный экспоненциальный шаг при постоянных входах; чистый входящий воздух, идеальное смешение, постоянный объём. В возврате взвешиваются Q_A+G_A, Q_B+G_B и чистый обход. Источник учтён в газовом балансе, но его влияние на аэродинамику пренебрегается. Это одностороннее приближение, не CFD.

## Последовательное наблюдение

IntervalObserver не получает скрытые R/G или эталонную концентрацию. Известны команды вентилятора/обхода, свежие показания и заявленные границы: R_A/R_B ∈[0,65;2,5] от базы; G_A/G_B ∈[0,5;2]. Параметры постоянны внутри шага, могут неизвестно меняться между шагами. Исходная концентрация известна как равновесие базового опыта; после явного перезапуска наблюдателя исходный диапазон [0;100]% сужается только свежими данными.

Экстремумы расходов находятся на углах диапазона сопротивлений для этой последовательно-параллельной топологии. Пересечение со свежими измерениями и интервальное распространение баланса QT=QA+QB+Qобхода сохраняют допустимые корреляции как избыточную ширину. Газовые границы распространяются монотонным решением баланса, затем пересекаются со свежими CA/CB. После потери датчика прежняя информация сохраняется, а ширина растёт со временем. Возвратный диапазон вычислен консервативными отношениями границ.

Пустое пересечение фиксирует конфликт; противоречивое измерение не принуждает интервал. Конфликт сохраняется до ремонта или явного перезапуска наблюдателя. Текущая конечная библиотека 256 гипотез оставлена только как отдельная номинальная диагностика: она не определяет интервалы и рейтинг. Среднее основного интервала — его середина, не математическое ожидание.

## Качество измерений

У каждого канала независимый генератор ограниченного равномерного шума с seed; опрос API не создаёт новый шум. Задержанные и зависшие пакеты показываются с временем и возрастом, но исключаются из текущего наблюдения. Отключённый канал хранит последнее полученное значение. Расходы QA/QB имеют допуск ±1,5 м³/с, QT ±2; CA/CB ±0,12 процентного пункта. Условное покрытие требует, чтобы суммарная ошибка свежего измерения укладывалась в допуск. Интерфейс разрешает более сильные ошибки для стресс-опытов.

## Выбор канала

W=ширина(CA)+ширина(CB), в процентных пунктах. Рейтинг оценивает немедленное уменьшение текущего W после одного восстановления, делённое на условную стоимость. Для CA/CB используется конечная квадратура: 25 равномерных состояний × ошибки −допуск/0/+допуск. Её равные веса — проектное предположение, не физические вероятности. Показываются ожидаемый, наихудший и наилучший выигрыши по этой квадратуре.

В данном наблюдателе новый расход не уточняет прошлую концентрацию мгновенно, поэтому его немедленный выигрыш равен нулю. Это ограничение выбранной цели и наблюдателя; будущая польза расхода не оценена. Нет графика работы бригад, времени ремонта и экономической стоимости. Восстановление в проверке даёт свежий несмещённый показанный эталон с сохранением допуска наблюдателя.

## Условия и пределы

Интервалы условны относительно топологии, начального состояния, границ R/G и ошибок. За пределами допущений возможен необнаруженный выход эталона из диапазона, особенно без измерений; это сохранено в стресс-тестах. Порог 1% об. и цель W=0,5 п.п. — настройки опыта, не нормативы. Нет полевой калибровки, подтверждения промышленной безопасности и статистической доверительной вероятности.
