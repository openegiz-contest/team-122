# Проверка версии bounded-interval-v2

Дата: 25 октября 2026. Команды выполняются из корня проекта.

- `python -m unittest discover -s tests -q` — 50 тестов прошли. HTTP-тесты требуют разрешённых loopback-соединений; в ограниченной песочнице их блокировал WinError 10013, после разрешения локальных соединений весь набор прошёл.
- `python -m app.reference` — воспроизведение стационарного опубликованного примера Gucheng: максимальное отличие расходов 1,014%, энергетическая невязка менее 10⁻⁶ Па, баланс узлов замкнут. Сравнение условно относительно внешних давлений и отсутствия дополнительной естественной тяги.
- `python -m app.evaluation` — полный отчёт `docs/evaluation.json`: 1536 случаев, 3840 проверок покрытия внутри допущений, нарушений 0. Это эмпирическая проверка, не вероятность надёжности.

## Сравнение решений

Матрица до расчёта: 16 сочетаний непрерывных скрытых параметров, 4 набора отказов, 2 режима вентилятора, 2 горизонта, 2 профиля ограниченного шума, 3 профиля условной стоимости. Контрфактические ремонты начинаются из копии одинакового состояния и RNG; другие каналы не переизмеряются.

| Стратегия | Среднее сокращение W / стоимость |
|---|---:|
| Рейтинг | 0,598158 |
| Фиксированный порядок | 0,523010 |
| Простая ширина / стоимость | 0,598158 |
| Равномерный случайный выбор | 0,291350 |
| Оракул с известным эталоном | 0,598158 |

Рейтинг лучше фиксированного в 272 случаях, равен в 1264. Совпадение с простым правилом во всех 1536 случаях не подтверждает пользу дополнительной сложности. Нулевое среднее отставание от оракула относится только к этой матрице. Средняя абсолютная ошибка прогноза выигрыша 0,027067 п.п. Полные поопытные записи, худшие результаты и группировки сохранены в JSON.

Десять стресс-опытов включают неизвестную смену источника, выход за границы, смещение, задержку и зависание при наличии/отсутствии измерений. Случай необнаруженного выхода эталона из интервала не исключён из отчёта.

## Интерфейс

В браузере проверены потеря/восстановление канала, фактическое сокращение W, контрольная точка, задержанное показание, загрузка опубликованного расчёта и отчёта. Скачанный JSON импортирован после сброса: модельное время, W и качество каналов совпали. При ширине 390px горизонтального переполнения документа нет; ошибки консоли при проверке не обнаружены. Это проверка основных путей, не исчерпывающая проверка всех устройств.

Интеграция с живыми MQTT/Ditto/Grafana в эти пять этапов не входила и заново не проверялась. Результаты старого конечного наблюдателя лежат в `docs/history` и не относятся к текущей версии.
