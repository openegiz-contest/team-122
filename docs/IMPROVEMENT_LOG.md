# Изменения v3

1. Аудит: подтверждены 50 прежних тестов, отдельный расчёт Gucheng и недостаток опубликованных газовых данных.
2. Основная сеть: девять ветвей, десять узлов, два вентилятора, знаковая связь и закрытие. Невязки и рабочие точки проверяются программно.
3. Газ: консервативный перенос по направлению воздуха, укрупнённые объёмы, синтетические источники, численные проверки шага и массы.
4. Каталог: единые ID, связи, единицы, происхождение и динамические состояния.
5. Наблюдение: конечные траектории без доступа к эталону, сохранение информации, объявленные неизвестные события, ошибки датчиков, конфликты. Гарантии v2 не перенесены.
6. Выбор измерения: прогноз, задержка ремонта, абсолютный целевой горизонт; матрица пяти стратегий и сохранённые проигрыши/отрицательный контроль.
7. Сценарии и UI: новая топология с прежними стилями, сравнение до/после, прогноз, журнал, график, JSON/CSV и воспроизведение.
8. Итоговая упаковка: документы, презентация, подписи и архив обновляются после проверки. Интеграция — последняя техническая стадия; её фактический статус отдельно в RELEASE_STATUS.md.

9. Живая интеграция завершена: 28 Things прочитаны из Ditto, проверены команды и ремонт. Брокерный сбой даёт HTTP 503 после устаревания снимка; после восстановления снова читается Ditto. Исправлены переносимость сборки Windows, LF для shell и передача истории графика через платформу. Локальные секреты и кэш внешнего API не включены в поставку.
