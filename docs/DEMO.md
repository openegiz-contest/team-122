# Демонстрация v3

Исходное состояние каждого независимого опыта: сброс, nA=nB=1, связь e5 открыта, все датчики исправны. Нажать «Зафиксировать до» (либо первая сценарная кнопка сделает это автоматически).

| Сценарий | Ожидаемая цепочка | Проверка |
|---|---|---|
| Вентилятор A 80% | Напор e8 ниже → меняются e6/e5/e7 → новый перенос газа | Стрелки, расходы, история V7 |
| Сопротивление e6 ×2 | e6 снижается, e5 и e7 меняются → V7 накапливает больше CH₄ | Δ расходов и Δ CH₄ в сравнении |
| Закрытие e5 | Qe5=0 → прекращение смешения через связь → изменение V6/V9 | Надпись «ЗАКРЫТО», нулевой расход |
| Газовыделение ×2 | Источники растут → узлы V5/V6 → V7/V9 | История и прогноз CH₄; расходы неизменны |
| Потеря группы датчиков | e6/V7/V9 недоступны, прежняя информация сохраняется | Возраст, качество, перечень используемых измерений |

Отмена: «Отменить воздействия» возвращает параметры и датчики, концентрации продолжают динамику. Сброс создаёт новый опыт и очищает журнал.

Для содержательного выбора ремонта: сброс → пауза → все датчики отключены → газовыделение ×2 → горизонт 120 с → выбрать канал в рейтинге → продолжить. Неизвестное изменение параметров расширяет гипотезы, сохраняя прежнюю концентрацию. Проверить время ремонта и фактическое ΔW к тому же целевому времени.

Ошибка датчика: зависание/задержка V7 исключаются из отбора. Смещение V7 +0,3 п.п. обычно даёт конфликт. При конфликте рекомендация отсутствует. После устранения ошибочного канала прежняя допустимая модель может снова согласоваться.

Воспроизведение: сохранить JSON → сбросить → «Воспроизвести JSON». Проверяется подпись модели. Пример: `docs/example-network.json`. Смена версии кода делает прежний опыт несовместимым.

Объекты можно выбирать мышью или клавишами Tab/Enter. Показать эталон метана — отдельный переключатель; расходы на схеме всегда явно обозначены как расчётный эталон.


Пространство: переключить метрическую схему, план и профиль; выбрать e6 и проверить 5000 м, 29,42 м², объём 147100 м³ и нулевую ошибку длины XYZ. Проверить слои Q/A и давления. Условные отметки и вертикальное преувеличение подписаны. Профиль сворачивает Y: совпадение линий в нём не означает совпадение ветвей в пространстве.

Польза: открыть блок «Проверка полезности», сравнить текущий разброс и приоритет метана, затем переключить параметры вне сетки. Показать конфликты и долю включения эталона, не только уменьшение W. Полный JSON скачивается рядом с таблицей.
