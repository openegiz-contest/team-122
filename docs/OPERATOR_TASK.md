# Задача инженера

Исследовать последствия изменения вентиляции и выбрать измерение, уменьшающее неопределённость прогноза CH₄. Объект — опубликованная эквивалентная сеть Gucheng с синтетическим газовым расширением. Решение — какой канал восстановить при ограниченной условной стоимости и различной задержке ремонта.

Результат отображается как W(H), текущие и прогнозные диапазоны, список каналов и сравнение до/после. Отсутствие расширения диапазона после отказа допустимо: прошлые измерения и детерминированная модель сохраняют информацию. Неопределённость неизвестного изменения режима вводится только через объявленное событие. Это лабораторная постановка, не наряд, аварийная автоматика или подтверждение безопасной работы.
