# Источник опубликованной сети

Jia T, Ma H, Gao K (2025). Decision on optimal airflow regulation solution set based on heat and airflow coupling characteristics of mine airflow in time series. PLOS ONE 20(5):e0320326. https://doi.org/10.1371/journal.pone.0320326

Лицензия статьи: CC BY 4.0. XML взят без изменений из пользовательского архива; SHA256: c761bb30d7e58953423582dc1b154361dce30e14250fe4923a3ea5795988a115. Таблица 4 — R, геометрия и контрольные расходы; рис. 3/8 — связи; раздел 4.1 — кривые. CSV является извлечением, топология — транскрипцией.

В v3 сеть стала основной моделью. В отличие от v2, геометрия используется для условного укрупнения объёмов: каждому внутреннему узлу назначена половина суммарного L·A прилегающих ветвей. Это наше модельное преобразование, а не опубликованные или измеренные эффективные объёмы смешения. Источники метана, датчики и ремонт синтетические; статья их не валидирует. Изменения воздушного режима и динамический газовый блок выполнены авторами VentObserve.
